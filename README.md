# 💎 Melantha Jewels. - Jewelry E-Commerce Storefront

A visually polished, responsive e-commerce web application designed for a luxury jewelry brand. This project demonstrates strong foundational front-end design skills, semantic markup, and clean CSS styling without the reliance on external frameworks.

## 📄 Website Structure
The project features a seamless four-page browsing experience:
* **Home Page:** Features a hero banner, promotional announcements, and curated featured collections.
* **Shop/Catalog:** A clean grid layout showcasing available jewelry items with hover effects.
* **About Us:** The brand story, mission statement, and artisan craftsmanship highlights.
* **Contact:** A fully designed customer service page featuring a styled inquiry form and store location details.

## 🛠️ Tech Stack
* **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) for optimal accessibility and SEO structure.
* **CSS3:** Custom layouts utilizing CSS Flexbox and Grid, custom transitions, hover states, and typography styling.
* **Deployment:** GitHub Pages.

## 🚀 Key Features
* **Fully Responsive:** Fluid layouts optimized across mobile, tablet, and desktop screens using CSS Media Queries.
* **Interactive UI Elements:** Smooth CSS hover transitions on navigation links, product images, and "Add to Cart" call-to-action buttons.
* **Clean Code Architecture:** Modular CSS properties to keep styling consistent across all four distinct pages.
